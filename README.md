# KPlayer

![Platform](https://img.shields.io/badge/platform-Windows-blue)
![Engine](https://img.shields.io/badge/engine-libmpv-green)
![License](https://img.shields.io/badge/license-GPL--2.0--or--later-lightgrey)

광고도, 애드웨어도, 군더더기도 없는 깔끔한 윈도우 미디어 플레이어.  
오픈 소스 미디어 엔진 **libmpv** 기반.

![KPlayer](https://kilho.net/wp-content/uploads/2026/03/K-949.png)

## 기능

- **38가지 형식** — 비디오 23종 (MP4, MKV, AVI, MOV, WMV, WebM, TS, M2TS, VOB, RM/RMVB 등),
  오디오 12종 (MP3, FLAC, AAC, M4A, WAV, OGG, Opus, WMA, APE, DSF 등), 재생목록 3종 (M3U, M3U8, PLS)
- 파일이나 폴더를 끌어다 놓으면 곧바로 추가 — 본체 창은 목록 교체, 재생목록 창은 덧붙임
- 재생목록 항목을 끌어서 순서 변경, 반복 재생과 랜덤 재생, 재생목록 저장
- 자막 켜기/끄기와 트랙 전환, 글꼴·색·외곽선·그림자·위치 설정
- 챕터 이동, 프레임 단위 이동, 배속 (0.25×–4.0×), 스크린샷 (PNG/JPG)
- `TAB` 정보 패널 — 파일·코덱·해상도·프레임 등 재생 정보
- 하드웨어 디코딩, 출력 드라이버·그래픽 API·화면 동기화·업스케일러·인터레이스 해제 선택
- 음량 평준화 (강도 선택)
- 파일 연결 — 환경설정에서 확장자별로 등록하고 Windows 기본 앱 선택 창을 바로 띄움
- **단축키와 마우스 동작을 모두 사용자 지정** (환경설정 '단축키' · '마우스' 카드)
- 다국어 — 한국어 · 영어 · 일본어 · 중국어 · 러시아어 · 이탈리아어 · 프랑스어 · 스페인어 · 아랍어 (OS 언어 자동)
- 프레임 없는 다크 UI, 항상 위, 새 버전 자동 확인

## 기본 단축키

모두 환경설정 → **단축키** 에서 바꿀 수 있다. `ESC`(전체 화면 해제)와 `TAB`(정보 패널)만 고정이다.

| 키 | 동작 |
|-----|--------|
| `Space` | 재생 / 일시정지 |
| `Enter` | 전체 화면 |
| `←` / `→` | 뒤로 / 앞으로 5초 |
| `Shift` + `←` / `→` | 뒤로 / 앞으로 1초 (정확) |
| `Ctrl` + `←` / `→` | 이전 / 다음 챕터 |
| `,` / `.` | 이전 / 다음 프레임 |
| `↑` / `↓` | 음량 +5 / −5 |
| `0` / `9` | 음량 +2 / −2 |
| `M` | 음소거 |
| `Page Up` / `Page Down` | 이전 / 다음 파일 |
| `V` | 자막 표시 / 숨김 |
| `J` / `Shift` + `J` | 다음 / 이전 자막 |
| `S` | 스크린샷 |
| `Z` | 배속 1.0× |
| `X` / `C` | 배속 −0.1 / +0.1 |
| `[` / `]` | 배속 −10% / +10% |

재생목록 · 환경설정 · 항상 위는 기본 키가 없고 컨트롤바 버튼으로 연다 (원하면 키를 지정할 수 있다).

## 마우스

환경설정 → **마우스** 에서 이벤트마다 기능을 고른다 (아무 작동 안 함 · 전체 화면 · 꽉찬 화면 · 재생/일시정지 · 다음/이전 파일 · 앞으로/뒤로 이동 · 볼륨 크게/작게).

| 이벤트 | 기본값 |
|-----|--------|
| 왼쪽 버튼 두 번 클릭 | 전체 화면 / 원래 화면 |
| 휠 위로 / 아래로 | 볼륨 크게 / 작게 |
| 왼쪽 버튼 한 번 클릭, 가운데 버튼 | 아무 작동 안 함 |

창은 아무 곳이나 끌어서 옮긴다.

## 환경설정

| 카드 | 항목 |
|-----|--------|
| 일반 | 반복 모드 · 랜덤 재생 · 재생목록 저장 · 스크린샷 폴더/형식 · 항상 위 · 재생 창 크기 |
| 영상 | 하드웨어 디코딩 · 출력 드라이버 · 그래픽 API · 화면 동기화 · 업스케일러 · 인터레이스 해제 |
| 음성 | 기본 볼륨 · 음량 평준화 · 평준화 강도 |
| 자막 | 기본 표시 · 크기 · 기본 언어 · 글꼴 · 굵게 · 글자색 · 외곽선 · 그림자 · 세로 위치 · 정렬 · 자막 파일 스타일 우선 |
| 연결 | 확장자별 등록 · 기본 앱 선택 |
| 단축키 | 동작 29종의 키 지정 |
| 마우스 | 클릭 · 더블클릭 · 가운데 버튼 · 휠 동작 |

설정은 `KPlayer.ini`, 재생목록은 `KPlayer.lst` 로 실행 파일 옆에 저장된다 (포터블).

## 설치

설치본은 `%LOCALAPPDATA%\KPlayer` 에 들어가며, 실행 파일 옆에 `libmpv-2.dll`, `KPlayer.lua`, `Icon\` 이 있어야 한다.  
직접 빌드하려면 Delphi (VCL, Win64) 와 [LibMPVDelphi](https://github.com/nbuyer/libmpvdelphi), [Virtual Treeview](https://github.com/JAM-Software/Virtual-TreeView), [SVGIconImageList](https://github.com/EtheaDev/SVGIconImageList) 가 필요하다.
