# KPlayer

![Platform](https://img.shields.io/badge/platform-Windows-blue)
![Engine](https://img.shields.io/badge/engine-libmpv-green)
![License](https://img.shields.io/badge/license-Freeware-lightgrey)

広告もアドウェアも余計な機能もない、シンプルな Windows 用メディアプレーヤー。  
オープンソースのメディアエンジン **libmpv** をベースにしています。

![KPlayer](https://kilho.net/wp-content/uploads/2026/03/K-949.png)

## 機能

- MP4、MKV、AVI、MOV、WMV、ASF、MP3 などに対応
- ファイルやフォルダーをドラッグ＆ドロップするだけですぐに追加
- プレイリストの項目をドラッグして並べ替え
- リピート再生とシャッフル再生

## 再生速度

| キー | 動作 |
|-----|--------|
| `Z` | 標準速度に戻す (1.0×) |
| `X` | 遅くする (−0.1×) |
| `C` | 速くする (+0.1×) |
| `[` / `]` | 微調整 (−10% / +10%) |

速度は 0.25×〜4.0× の範囲に制限され、変更すると現在の値が画面に短時間表示されます。
